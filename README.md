# 💸 Full Stack Expense Tracker

A full-stack expense tracking application that allows users to manage their daily expenses efficiently with authentication, filtering, and real-time updates.
> 🚀 Built as a full-stack project to demonstrate backend API design, authentication, and real-world CRUD operations.
---

## 🚀 Features

* 🔐 User Authentication (Signup/Login)
* ➕ Add new expenses
* 🗑️ Delete expenses
* ✏️ Update existing expenses
* 🔍 Filter expenses based on criteria
* 📊 (Upcoming) Expense visualization with charts

---

## 🛠️ Tech Stack

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* RESTful APIs for expense management

### Frontend

* React.js
* Axios
* CSS / Tailwind 

---

## 📁 Project Structure

```
/backend     → Express server, APIs, database
/frontend    → React UI
```

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/<your-username>/fullstack-expenseTracker.git
```

### 2. Setup Backend

```
cd backend
npm install
npm run dev
```

### 3. Setup Frontend

```
cd frontend
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file in the backend folder and add:

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
